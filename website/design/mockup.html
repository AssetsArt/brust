Sixty seconds to a served page

No config to write first. The template already has a layout, a page and the scripts.

  1. 1

    Create

    One command scaffolds the project and installs its dependencies.

  2. 2

    Write

    A page is a React component. There is nothing to import from brust.

  3. 3

    Run

    Build compiles every component; start serves them from Rust.

One component model, three outputs

You write ordinary React. The compiler reads each component, picks the cheapest output that still behaves the same, and tells you what it picked. Left is the code, right is what the browser shows.

    Data stays next to the route

    Each route names its loader, and layouts nest through Outlet with their loader results merged top-down.

    1. 1Params arrive decoded, including encoded slashes.
    2. 2The loader runs in Bun with the request in hand and returns the page's props.
    3. 3Caching is one line. A hit is answered by Rust and never wakes Bun.
    4. 4Invalidate by tag from wherever the data changed.

    Actions, typed end to end

    One Elysia app, served by Rust under /_brust/action. The browser gets a client that knows every route and its types.

    One store, both sides

    Define a store once. The server fills it while rendering, the browser picks it up as a snapshot, and native components and islands read the same signals.

    Deploy where you like

    The same routes file builds for a Bun process on your own machine or for Cloudflare Workers. Nothing in the app changes.

    Your server

    A Rust server handles HTTP; Bun workers run loaders and actions beside it.

    Cloudflare Workers

    The build emits a Worker, the static assets and a merged wrangler.jsonc. D1 and KV bind as usual.

    Packages

    Install only what the app uses. Everything publishes in lockstep at the same version.

    @brust/core

    Routes, loaders, cache, actions, store, the CLI and the native server.

    bun add @brust/core
    @brust/create-app

    The scaffolder behind bun create @brust/app.

    bun create @brust/app@latest
    @brust/core-cf

    The same runtime as a Worker, used by the Cloudflare target.

    installed with @brust/core
    @brust/runtime-dom

    The browser runtime for native components: signals and bindings.

    installed with @brust/core
    @brust/cache-redis

    A shared cache tier on Redis or Dragonfly, with invalidation across instances.

    bun add @brust/cache-redis
    @brust/cache-cloudflare

    The shared tier on KV, with a Durable Object for invalidation.

    bun add @brust/cache-cloudflare

    What brust is not

    Fewer surprises if you know the shape before you start.

    a single-page app

    Navigation is server-first. Pages render on the server; islands hydrate only where they appear.

    file-system routing

    Routes live in one explicit routes.tsx, so you can read the whole site in one file.

    a React replacement

    Islands run real React 19. The compiler only steps in where React would be dead weight.

    Read the quickstart, then ship something small.

    Guide / Quickstart

    Quickstart

    From an empty folder to a page served by Rust. Four steps, each one a command or a file you can copy as is.

    1Check the requirements

    Bun 1.4 or newer. The Rust server ships prebuilt for macOS and Linux, so there is no Rust toolchain to install.

    2Create the project

    The blank template has one layout, one page, and the scripts you will use every day.

    Note

    Keep the @latest. bun create caches the scaffolder, and a stale cache gives you an old template.

    3Write a page

    A page is a plain React component. routes.tsx maps paths to components, and the layout wraps every page through Outlet.

    This page has no state and no handlers, so the compiler marks it static: rendered once, served as HTML, no client JavaScript.

    4Run it

    bun run dev builds and starts the server. Open the address it prints.

    5Where to go next

    • Routing: nested layouts, path params, the catch-all 404.
    • Loaders and params: fetch data per route in Bun.
