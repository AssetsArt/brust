> **Read the deltas, not the absolutes.** This run was taken on a *loaded* dev
> machine (a concurrent test suite was running), so every row — including the
> brust-independent `Bun.serve` baselines — is ~10–18% below the 2026-05-31
> clean run. That uniform drop across unrelated servers confirms it is
> environmental, **not** a code regression. The meaningful signals here: the
> relative ordering is unchanged, and the migrated server-action wire
> (`POST /_brust/action/notes`, replacing the old `/createNote`) lands at
> 60,194 RPS — right on the ~60k napi-crossing floor (see memory
> `napi-crossing-floor`), i.e. the new treaty dispatch carries no measurable
> overhead vs the old wire. Canonical absolute numbers want a clean-machine /
> Linux re-measure.
