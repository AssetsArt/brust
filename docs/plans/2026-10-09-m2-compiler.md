**Goal:** Make `crates/brust-compiler` emit everything the M2 server and build need (document roots, `Outlet`, the react island host, server-seeded `useId`, per-instance child records and `use_id_slots` in the IR JSON) and close the compiler ledger items that M2 inherits (F33, F37, F40, F41, F42, F49).

**Architecture:** every change is local to one analysis pass or the template backend; the IR JSON (`--emit ir`) is the contract the `m2c` build lane reads to write `dist/manifest.json`, so new IR fields are added with serde defaults and golden fixtures. No change to the client printer except the `Outlet` no-op and the `_idN` client prop.

**Tech Stack:** Rust nightly per `rust-toolchain.toml`, Bun crates at the pinned rev, `cargo test -p brust-compiler`, fixture goldens via `BRUSTC_UPDATE=1 cargo test -p brust-compiler --test fixtures`, battery `bun run battery`.

**Spec:** `docs/design/2026-10-09-m2-server-design.md` S6 (manifest fields), S7 step 6 (useId), S8 (Outlet), S9 (document is JSX), S12 (island host), §5 F33; ledger `docs/plans/m1a-followups.md` F33, F34 (instance records only), F37, F39, F40, F41, F42, F49. Compiler spec `docs/design/2026-10-08-react-compiler-design.md` §3, §4.3, §6.2, §8.1.

## Global Constraints

- Fail closed: anything the compiler cannot prove native produces a `Fallback` diagnostic (tier `react`), never silently wrong output. A panic on valid TSX is a blocker (F38/F42 rule).
- Autoescape stays `None`; every dynamic text/attr output goes through `| e` (or `json_attr`/`safe` where the spec names them).
- New IR fields are `#[serde(default)]` so existing `expected.ir.json` goldens only change where the plan says; regenerate goldens with the update command and inspect every diff (bump checklist step 8 rule).
- Rule names are string literals at the raise site (no table exists); new rules used here: `outlet-outside-layout` is NOT a compiler rule (the build lane raises it), `use-client-leftover`, `effect-deps`, `memo-shape`.
- Gates before every commit: `cargo fmt --all`, `cargo clippy -p brust-compiler -p brust-compiler-cli -p brust-jinja --no-deps -- -D warnings`, `cargo test -p brust-compiler`.
- After the last task: `bun run battery` twice (no diff), `bun test scripts/battery`, `bun run browser-test`, `cargo test --workspace --exclude bun_react_compiler`.
- Boundary: `crates/brust-compiler/**`, `crates/brust-compiler-cli/**`, `tests/fixtures/**`, `tests/browser/**`, `scripts/battery/**`, `docs/react-coverage.md`, `docs/plans/m1-exit-report.md`, `docs/plans/m1a-followups.md` (close rows), `docs/design/2026-10-08-react-compiler-design.md` (§ amendments named per task).

## Review Focus

1. **`<html>` root with `<head><title>{x}</title></head>`**: the title text must be escaped and the `x-data` host must land on `<body>`'s first element, not on `<html>` — Task 1's fixture pins the exact jinja.
2. **`useId` in a keyed row** (per-item ids): ids must differ per row and be stable across requests; Task 4 pins `_id0` indexed by the loop path.
3. **`memo(Inner, cmp)` with a comparator**: still unwrapped (the comparator is ignored natively, documented); `memo(forwardRef(X))` stays react — Task 6 pins both.
4. **`Array.from(xs, (x, i) => <li key={x.id}/>)`** with the index param: keyed-row rules apply exactly as `.map` — Task 7 pins it.
5. **A dynamic `import()` inside a class method inside a component** (Afrojack's repro): Fallback `dynamic-import`, never a panic — Task 9 pins it with the exact repro.
