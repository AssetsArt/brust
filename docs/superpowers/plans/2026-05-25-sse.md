# Server-Sent Events (SSE) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mount `text/event-stream` routes via a new `Route.sse: (req) => ReadableStream` field, served through a new long-lived tsfn dispatch with NAPI write/close/abort/open channels.

**Architecture:** Rust assigns a `conn_id`, writes SSE headers only after middleware approves (via `napi_sse_signal_open` reverse-direction callback), then a per-connection tokio task pumps `mpsc<SseFrame>` to the TCP socket while the worker's JS glue reads chunks from the author's ReadableStream and writes via `napi_sse_write(conn_id, bytes)`. Many connections multiplex on one worker — the existing `pool.pick_least_busy()` keeps `in_flight_guard` alive for the connection's lifetime; Bun's JS event loop multiplexes between streams + render + action.

**Tech Stack:** Rust 2024 + tokio (mpsc, oneshot, AtomicU64) + parking_lot::Mutex (existing dep), Bun 1.4 with NAPI `napi-rs` (existing), TypeScript, `bun:test`, no new Rust or JS deps.

**Spec:** `docs/superpowers/specs/2026-05-25-sse-design.md`

```rust
//! SSE per-connection state.
//!
//! Each accepted SSE connection lives in REGISTRY, keyed by a monotonic
//! conn_id. The Rust per-connection tokio task reads SseFrame values from
//! the JS-driven mpsc::Sender and writes them to the TCP socket. The
//! oneshot open channel carries the middleware verdict back from JS so
//! Rust can decide whether to write SSE headers or a regular 4xx response.

use parking_lot::Mutex;
use std::collections::HashMap;
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::OnceLock;
use tokio::sync::{mpsc, oneshot};

pub static NEXT_CONN_ID: AtomicU64 = AtomicU64::new(1);

pub fn next_conn_id() -> u64 {
    NEXT_CONN_ID.fetch_add(1, Ordering::Relaxed)
}

/// One framed write request from JS glue → Rust per-conn task.
pub struct SseFrame {
    pub bytes: Vec<u8>,
    /// Resolved after Rust completes the TCP write; the JS Promise from
    /// napi_sse_write awaits this signal to provide cooperative backpressure.
    pub ack: oneshot::Sender<()>,
}

/// Middleware verdict carried back via napi_sse_signal_open.
pub struct SseOpenSignal {
    pub status: u16,
    pub body: Vec<u8>,
    pub content_type: String,
}

/// Per-connection state stored in REGISTRY.
pub struct SseConn {
    /// JS writes chunks → enqueues here. Bounded at 32 frames for backpressure.
    pub frame_tx: mpsc::Sender<SseFrame>,
    /// JS signals middleware verdict here. Single-shot.
    pub open_tx: Option<oneshot::Sender<SseOpenSignal>>,
    /// Optional JS-registered abort callback (set via napi_sse_register_abort).
    /// Fired by the per-conn task when client TCP closes.
    pub abort_cb: Option<Box<dyn FnOnce() + Send + 'static>>,
}

pub type Registry = Mutex<HashMap<u64, SseConn>>;

static REGISTRY: OnceLock<Registry> = OnceLock::new();

pub fn registry() -> &'static Registry {
    REGISTRY.get_or_init(|| Mutex::new(HashMap::new()))
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn next_conn_id_is_monotonic_and_unique() {
        let a = next_conn_id();
        let b = next_conn_id();
        let c = next_conn_id();
        assert!(b > a);
        assert!(c > b);
        assert_ne!(a, b);
    }

    #[tokio::test(flavor = "current_thread")]
    async fn registry_insert_remove_round_trip() {
        let (frame_tx, _frame_rx) = mpsc::channel(32);
        let (open_tx, _open_rx) = oneshot::channel::<SseOpenSignal>();
        let id = next_conn_id();
        registry().lock().insert(id, SseConn {
            frame_tx,
            open_tx: Some(open_tx),
            abort_cb: None,
        });
        assert!(registry().lock().contains_key(&id));
        let removed = registry().lock().remove(&id);
        assert!(removed.is_some());
        assert!(!registry().lock().contains_key(&id));
    }
}
```

```rust
use tokio::io::{AsyncRead, AsyncReadExt};

/// Awaits the next byte from `stream` and returns when the peer has closed
/// the connection (FIN or RST). On any error (including non-existent data
/// after FIN) the future resolves. The function does NOT consume application
/// bytes — by spec, SSE clients never send body after the initial request,
/// so any read here means "the connection is going away."
pub async fn peek_for_close<S: AsyncRead + Unpin>(stream: &mut S) -> () {
    let mut byte = [0u8; 1];
    // read returns Ok(0) on clean FIN; Err on RST or other failures.
    let _ = stream.read(&mut byte).await;
    // Either way, we treat it as "close imminent" and return.
}
```

```rust
use crate::sse::{registry, SseConn, SseFrame, SseOpenSignal};
use napi::bindgen_prelude::*;
use napi::threadsafe_function::{ThreadsafeFunction, ThreadsafeFunctionCallMode};
use tokio::sync::oneshot;

/// Enqueue one SSE frame for the given connection. Returns a Promise that
/// resolves when the Rust-side per-conn task has finished the TCP write —
/// cooperative backpressure for the JS reader loop.
#[napi]
pub async fn napi_sse_write(conn_id: BigInt, bytes: Buffer) -> Result<()> {
    let conn_id = bigint_to_u64(&conn_id)?;
    let frame_tx = {
        let reg = registry().lock();
        reg.get(&conn_id).map(|c| c.frame_tx.clone())
    };
    let Some(tx) = frame_tx else {
        return Err(Error::new(Status::GenericFailure, format!("conn {} not registered", conn_id)));
    };
    let (ack_tx, ack_rx) = oneshot::channel::<()>();
    let frame = SseFrame { bytes: bytes.to_vec(), ack: ack_tx };
    if tx.send(frame).await.is_err() {
        return Err(Error::new(Status::GenericFailure, format!("conn {} channel closed", conn_id)));
    }
    let _ = ack_rx.await; // Resolves when Rust task acknowledges TCP write.
    Ok(())
}

/// Drop the connection's sender, which signals the per-conn task to exit
/// and close the TCP socket. Idempotent — a missing conn is a no-op.
#[napi]
pub fn napi_sse_close(conn_id: BigInt) -> Result<()> {
    let conn_id = bigint_to_u64(&conn_id)?;
    let _ = registry().lock().remove(&conn_id);
    Ok(())
}

/// JS provides a callback (JsFunction) that fires once when Rust detects
/// client disconnect. Stored as a thread-safe wrapper on the SseConn.
#[napi]
pub fn napi_sse_register_abort(env: Env, conn_id: BigInt, cb: JsFunction) -> Result<()> {
    let conn_id = bigint_to_u64(&conn_id)?;
    let tsfn: ThreadsafeFunction<()> = cb.create_threadsafe_function(0, |_| Ok(Vec::<()>::new()))?;
    let mut reg = registry().lock();
    if let Some(conn) = reg.get_mut(&conn_id) {
        conn.abort_cb = Some(Box::new(move || {
            tsfn.call(Ok(()), ThreadsafeFunctionCallMode::NonBlocking);
        }));
    }
    Ok(())
}

/// JS reports the middleware open verdict. Single-shot — second call is dropped.
#[napi]
pub fn napi_sse_signal_open(conn_id: BigInt, status: u32, body: Buffer, content_type: String) -> Result<()> {
    let conn_id = bigint_to_u64(&conn_id)?;
    let open_tx = {
        let mut reg = registry().lock();
        reg.get_mut(&conn_id).and_then(|c| c.open_tx.take())
    };
    if let Some(tx) = open_tx {
        let _ = tx.send(SseOpenSignal {
            status: status as u16,
            body: body.to_vec(),
            content_type,
        });
    }
    Ok(())
}

fn bigint_to_u64(b: &BigInt) -> Result<u64> {
    let (signed, value, _lossless) = b.get_u64();
    if signed {
        return Err(Error::new(Status::InvalidArg, "conn_id must be non-negative"));
    }
    Ok(value)
}
```

NOTE: BigInt is used because Bun's NAPI Buffer doesn't natively support u64 (JS Number tops out at 2^53). Worker side passes conn_id as BigInt. The JS NAPI binding will surface these as `bigint`-typed args.

If `bigint_to_u64` already exists in `napi.rs` (for other features), reuse it; otherwise the version above is correct.

```rust
/// Per-connection driver loop. Owns the TCP stream after the open-signal
/// arrives + headers are written. Forwards frames to the wire, ack-ing
/// each one so JS Promises resolve. Exits on peer close OR sender drop.
pub async fn sse_conn_task<S>(
    mut stream: S,
    conn_id: u64,
    mut frame_rx: mpsc::Receiver<SseFrame>,
) where
    S: tokio::io::AsyncRead + tokio::io::AsyncWrite + Unpin,
{
    loop {
        tokio::select! {
            maybe_frame = frame_rx.recv() => {
                match maybe_frame {
                    Some(frame) => {
                        if stream.write_all(&frame.bytes).await.is_err() { break; }
                        let _ = frame.ack.send(());
                    }
                    None => break, // sender dropped — graceful close
                }
            }
            _ = peek_for_close(&mut stream) => {
                // peer closed mid-stream
                break;
            }
        }
    }
    // Cleanup: remove from REGISTRY and fire abort callback if set.
    let conn = registry().lock().remove(&conn_id);
    if let Some(mut c) = conn {
        if let Some(cb) = c.abort_cb.take() { cb(); }
    }
    let _ = stream.shutdown().await;
}
```

```rust
        let envelope_json = crate::routes::build_sse_envelope(
            &method, &path, &buf[..header_end], conn_id,
        );
        let dispatch_fut = crate::pool::dispatch_sse(entry, envelope_json, conn_id);

        // Await the open signal.
        let open = match tokio::time::timeout(std::time::Duration::from_secs(30), open_rx).await {
            Ok(Ok(signal)) => signal,
            _ => {
                let _ = s.write_all(http::error_500()).await;
                crate::sse::registry().lock().remove(&conn_id);
                return;
            }
        };

        if open.status >= 400 {
            // Worker rejected (likely middleware). Write a regular HTTP response.
            let body = String::from_utf8_lossy(&open.body).to_string();
            let resp = format!(
                "HTTP/1.1 {} {}\r\nContent-Type: {}\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{}",
                open.status,
                http::status_reason(open.status),
                open.content_type,
                body.len(),
                body,
            );
            let _ = s.write_all(resp.as_bytes()).await;
            crate::sse::registry().lock().remove(&conn_id);
            return;
        }

        // Open OK — write SSE headers, hand the socket to the per-conn task.
        if crate::sse::write_sse_response_headers(&mut s).await.is_err() {
            crate::sse::registry().lock().remove(&conn_id);
            return;
        }

        // Run the per-conn task until completion (dispatch_fut keeps the worker pinned).
        let task_fut = crate::sse::sse_conn_task(s, conn_id, frame_rx);
        let _ = tokio::join!(task_fut, dispatch_fut);
        // _guard dropped here → worker in_flight decremented.
        return;
    }
}
```

```rust
/// Fire a single tsfn call carrying the SSE envelope and conn_id. The call
/// lives for the entire connection lifetime — the JS side runs middleware,
/// signals open via napi_sse_signal_open, then enters the reader loop. This
/// future resolves only when the JS handler returns (stream done or error).
pub async fn dispatch_sse(
    entry: Arc<TsfnEntry>,
    envelope_json: String,
    _conn_id: u64,
) {
    // The tsfn payload is just the envelope JSON; conn_id is inside the JSON.
    // The worker's makeRenderer dispatches by kind: 'sse' → sseBranch → handleSseStream.
    // Use a oneshot to await JS completion.
    let (done_tx, done_rx) = tokio::sync::oneshot::channel::<()>();
    let payload = SseTsfnPayload { envelope_json, done: done_tx };
    let status = entry.tsfn.call(
        Ok(payload.into_napi_value()),
        napi::threadsafe_function::ThreadsafeFunctionCallMode::NonBlocking,
    );
    if !matches!(status, napi::Status::Ok) {
        // tsfn dispatch failed (worker dead?). Drop oneshot — JS side is gone.
        return;
    }
    let _ = done_rx.await;
```

```ts
import type { Route, BrustRequest, RouteCall } from '../routes.ts'

export type SseCall = Extract<RouteCall, { kind: 'sse' }>

/** NAPI surface — Rust provides these. In tests, a mock satisfies the shape. */
export interface SseNapi {
  write(conn_id: bigint, bytes: Uint8Array): Promise<void>
  close(conn_id: bigint): void
  registerAbort(conn_id: bigint, cb: () => void): void
  signalOpen(conn_id: bigint, status: number, body: string, contentType: string): void
}

const encoder = new TextEncoder()
const PING_FRAME = encoder.encode(': ping\n\n')

/** Module-level convenience used by sseBranch's stub before Task 8 lands. */
export function signalOpen(
  conn_id: bigint,
  status: number,
  body: string,
  contentType: string,
): void {
  // The real production path injects napi via Task 12 wiring; this top-level
  // export exists so the stub sseBranch (Task 7) can compile. Throw if called
  // in production without an injected napi — Task 12 replaces the sseBranch
  // body to call the handler directly with a real napi.
  throw new Error('signalOpen called without napi injection — see Task 12 wiring')
}

export async function handleSseStream(
  call: SseCall,
  route: Route,
  napi: SseNapi,
): Promise<void> {
  // 1. Create per-conn AbortController; install on req.signal.
  const controller = new AbortController()
  ;(call.req as Mutable<BrustRequest>).signal = controller.signal

  // 2. Wire Rust→JS abort.
  napi.registerAbort(call.conn_id, () => controller.abort())

  // 3. Open the user's stream. Throw → signal 500 and close.
  let stream: ReadableStream<Uint8Array | string>
  try {
    stream = await route.sse!(call.req)
  } catch (err) {
    const msg = err instanceof Error ? err.message : String(err)
    napi.signalOpen(call.conn_id, 500, `sse handler threw: ${msg}`, 'text/plain; charset=utf-8')
    napi.close(call.conn_id)
    return
  }

  // 4. Signal open OK — Rust writes SSE response headers.
  napi.signalOpen(call.conn_id, 200, '', 'text/event-stream')

  // 5. Heartbeat + reader loop.
  const reader = stream.getReader()
  const heartbeatMs = route.sseOptions?.heartbeatMs ?? 15_000
  const heartbeatId = heartbeatMs > 0
    ? setInterval(() => { void napi.write(call.conn_id, PING_FRAME) }, heartbeatMs)
    : null

  // Force-cancel reader on abort so a stuck `await reader.read()` unwinds
  // even if the author didn't listen to req.signal.
  controller.signal.addEventListener('abort', () => { void reader.cancel() })

  try {
    while (true) {
      const { value, done } = await reader.read()
      if (done) break
      const bytes = typeof value === 'string' ? encoder.encode(value) : value
      await napi.write(call.conn_id, bytes)
    }
  } catch (err) {
    if (!controller.signal.aborted) {
      console.error(`[brust] sse stream error conn=${call.conn_id}:`, err)
    }
  } finally {
    if (heartbeatId !== null) clearInterval(heartbeatId)
    napi.close(call.conn_id)
    try { reader.releaseLock() } catch {}
  }
}

type Mutable<T> = { -readonly [P in keyof T]: T[P] }
```

```ts
import type { BrustRequest } from '../../runtime/routes.ts'

/** Emits 3 data frames at 50ms intervals then closes. */
export function counterStream(req: BrustRequest): ReadableStream<string> {
  return new ReadableStream({
    start(controller) {
      let n = 0
      const id = setInterval(() => {
        controller.enqueue(`data: ${++n}\n\n`)
        if (n >= 3) {
          clearInterval(id)
          controller.close()
        }
      }, 50)
      req.signal.addEventListener('abort', () => {
        clearInterval(id)
        ;(globalThis as { __lastSseAbort?: number }).__lastSseAbort = Date.now()
      })
    },
  })
}

/** Never enqueues — used to assert the framework's heartbeat fires. */
export function idleStream(req: BrustRequest): ReadableStream<string> {
  return new ReadableStream({
    start(controller) {
      req.signal.addEventListener('abort', () => controller.close())
    },
  })
}
```

```ts
async function sseBranch(
  call: Extract<RouteCall, { kind: 'sse' }>,
  view: Uint8Array,
  encoder: TextEncoder,
  routes: FlatRoute[],
): Promise<number> {
  // Find the matching route by path. MVP: literal match.
  const route = routes.find((r) => r.fullPath === call.req.url.split('?')[0])
  if (!route || !route.chain[route.chain.length - 1].sse) {
    // Shouldn't happen — registerSsePaths gates Rust dispatch — but be defensive.
    const { native } = await import('./native.ts')
    native.napi_sse_signal_open(call.conn_id, 404, 'not found', 'text/plain')
    return packResponse(view, encoder, { status: 200, body: '', contentType: 'text/plain' })
  }
  const leaf = route.chain[route.chain.length - 1]

  // Run middleware chain — composeChain with a 200 placeholder terminal.
  const placeholderTerminal = async () => ({
    status: 200, body: '', contentType: 'text/event-stream',
  })
  const chain = composeChain(call.req, leaf.middleware, placeholderTerminal)
  const verdict = await chain()

  const { native } = await import('./native.ts')
  const napi = {
    write: (conn_id: bigint, bytes: Uint8Array) =>
      native.napi_sse_write(conn_id, bytes),
    close: (conn_id: bigint) =>
      native.napi_sse_close(conn_id),
    registerAbort: (conn_id: bigint, cb: () => void) =>
      native.napi_sse_register_abort(conn_id, cb),
    signalOpen: (conn_id: bigint, status: number, body: string, ct: string) =>
      native.napi_sse_signal_open(conn_id, status, new TextEncoder().encode(body), ct),
  }

  if (verdict.status >= 400) {
    napi.signalOpen(call.conn_id, verdict.status, verdict.body, verdict.contentType ?? 'text/plain')
    napi.close(call.conn_id)
    return packResponse(view, encoder, { status: 200, body: '', contentType: 'text/plain' })
  }

  // Middleware OK — invoke the handler.
  const { handleSseStream } = await import('./sse/handler.ts')
  const sseCall = { ...call, req: call.req } as Extract<RouteCall, { kind: 'sse' }>
  // Construct Route shim with sse + sseOptions for handler.
  const routeShim: Route = {
    path: route.fullPath,
    sse: leaf.sse,
    sseOptions: leaf.sseOptions,
  }
  await handleSseStream(sseCall, routeShim, napi)
  return packResponse(view, encoder, { status: 200, body: '', contentType: 'text/event-stream' })
}
```

```ts
async function openSseConn(port: number, path: string, headers: Record<string, string> = {}) {
  const ctrl = new AbortController()
  const resp = await fetch(`http://127.0.0.1:${port}${path}`, {
    method: 'GET',
    headers: { accept: 'text/event-stream', ...headers },
    signal: ctrl.signal,
  })

}

async function readAllText(resp: Response, maxBytes = 4096, maxMs = 2000): Promise<string> {
  const reader = resp.body!.getReader()
  const chunks: Uint8Array[] = []
  const start = Date.now()
  let total = 0
  while (Date.now() - start < maxMs) {
    const { value, done } = await Promise.race([
      reader.read(),
      new Promise<{ done: true; value: undefined }>((resolve) =>
        setTimeout(() => resolve({ done: true, value: undefined }), 100)),
    ])
    if (done) break
    if (value) {
      chunks.push(value)
      total += value.byteLength
      if (total >= maxBytes) break
    }
  }
  reader.cancel().catch(() => {})
  return new TextDecoder().decode(new Uint8Array(chunks.flatMap((c) => Array.from(c))))
}
```
