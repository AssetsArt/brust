## Task 1.2 — static-route enumeration

**Files:** `runtime/cli/ssg.ts` (new), `runtime/cli/ssg.test.ts` (new).

```ts
export interface SsgRouteDecision {
  fullPath: string
  include: boolean
  reason?: 'dynamic-param' | 'wildcard' | 'sse' | 'websocket'
  outFile: string // 'index.html' | 'docs/intro/index.html' …
}
export function collectStaticPaths(flatRoutes: FlatRouteLike[]): SsgRouteDecision[]
```

- Input is the `routes` array the routes module exports (same shape `runBuild`
  already imports at build.ts:247 — reuse, do NOT add an introspection endpoint;
  this resolves spec open question 4).
- Skip rules: fullPath containing `{`…`}` segment → `dynamic-param`; `*` →
  `wildcard`; leaf chain node with `sse` → `sse`; with `websocket` → `websocket`.
  (`native: true` cannot coexist with sse/ws — routes.ts:392-396 — but TSX sse/ws
  routes exist; check the LEAF node of `chain`.)
- `outFile` mapping: `/` → `index.html`; `/docs/intro` → `docs/intro/index.html`;
  trailing-slash dedupe.
- Tests: each skip reason, mapping cases, deterministic order.

Verify: `bun test runtime/cli/ssg.test.ts`.

## Task 1.3 — crawl + export

**Files:** `runtime/cli/ssg.ts`, `runtime/cli/ssg.test.ts`.

```ts
export async function exportStatic(opts: {
  distDir: string      // the just-built outDir
  entryDir: string     // app dir (for public/)
  staticOut: string    // dist/static (clobbered first)
  routes: SsgRouteDecision[]
}): Promise<{ written: string[]; skipped: SsgRouteDecision[] }>
```

- Boot: `Bun.spawn(['bun', join(distDir,'index.js')], { env: { BRUST_PORT: String(port), BRUST_WORKERS: '1' }, stdout: 'pipe', stderr: 'pipe' })`.
  Port via the `freePort()` pattern (`tests/integration.test.ts:8-18` — copy the
  helper, do not import from tests/). Readiness: read child stdout until the line
  containing `[brust] listening on` (precedent integration.test.ts:1273-1275);
  timeout 30s → kill + throw with captured output.
- Crawl serially or small concurrency (≤4): `GET http://127.0.0.1:{port}{path}`.
  ANY non-200 → kill child, `throw` (build fails, no partial site) including path +
  status + first 500 bytes of body.
- Write bodies to `staticOut/<outFile>`.
- Asset copy preserving URL shape: `distDir/islands/*` →
  `staticOut/_brust/islands/`, `distDir/css/*` → `staticOut/_brust/css/`,
  `entryDir/public/*` → `staticOut/` (check actual served URL for public assets in
  the Rust static handler and match it — verify with a curl against the booted
  fixture before hardcoding).
- ALWAYS kill the child (try/finally) — orphaned servers break later port-race
  tests (known flake class).
- Tests: use the existing fixture app (`tests/fixtures/app`) built into a tmp dir —
  follow `runtime/cli/build.test.ts` / `tests/cli-build.test.ts` patterns. Assert:
  written file set, non-200 path (add a throwing fixture route? if too invasive,
  simulate by requesting a 404 path in the decision list), child process is dead
  after both success and failure paths.

**BLOCKED fallback:** if stdout readiness-line parsing is flaky under `Bun.spawn`
pipes, poll `GET /` with retries instead (200/any-HTTP-response = ready).

Verify: `bun test runtime/cli/ssg.test.ts` (run twice to catch port races).
