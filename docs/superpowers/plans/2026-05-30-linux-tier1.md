## T2 — Fork: AsyncRead/AsyncWrite for TcpStream

Reviewer-confirmed sound: `Op<Read<Vec<u8>>>`/`Op<Write<Vec<u8>>>` are `Future + Unpin`, hold an owned `SharedFd` clone, need `CONTEXT` only at submit (first poll), drop-safe (`Lifecycle::Ignored` keeps the buffer alive until CQE).

New `src/io/poll_compat.rs` in the fork (and `mod poll_compat;` in `src/io/mod.rs`):

```rust
// Bridges tokio_uring's completion IO to tokio's poll-based AsyncRead/AsyncWrite,
// so tokio-tungstenite can drive a uring TcpStream. Single-thread only (the
// tokio_uring runtime); ops submit on the first poll where CONTEXT is set.
use std::io;
use std::pin::Pin;
use std::task::{Context, Poll};
use tokio::io::{AsyncRead, AsyncWrite, ReadBuf};
use crate::io::SharedFd;
use crate::io::read::Read;        // pub(crate) — adapter is in-crate
use crate::io::write::Write;      // (WriteData / Write op — confirm exact name)
use crate::runtime::driver::op::Op;

pub struct PollИo { fd: SharedFd, rd: Option<Op<Read<Vec<u8>>>>, wr: Option<Op<Write<Vec<u8>>>> }
// (name it PollIo; expose `TcpStream::into_poll_io(self) -> PollIo` built from inner fd clone)

impl AsyncRead for PollIo {
  fn poll_read(mut self: Pin<&mut Self>, cx: &mut Context<'_>, buf: &mut ReadBuf<'_>) -> Poll<io::Result<()>> {
    if self.rd.is_none() {
      let cap = buf.remaining().min(64 * 1024);
      // submit a read op owning a fresh Vec (uring needs a stable owned buffer)
      self.rd = Some(/* Op::read at offset 0 with Vec::with_capacity(cap) — use the crate's read ctor */);
    }
    let op = self.rd.as_mut().unwrap();
    match Pin::new(op).poll(cx) {
      Poll::Pending => Poll::Pending,
      Poll::Ready((res, owned)) => { self.rd = None; let n = res?; buf.put_slice(&owned[..n]); Poll::Ready(Ok(())) }
    }
  }
}
impl AsyncWrite for PollIo {
  fn poll_write(mut self: Pin<&mut Self>, cx, buf: &[u8]) -> Poll<io::Result<usize>> {
    if self.wr.is_none() { self.wr = Some(/* Op::write owning buf.to_vec() */); }
    let op = self.wr.as_mut().unwrap();
    match Pin::new(op).poll(cx) { Pending=>Pending, Ready((res,_owned))=>{ self.wr=None; Poll::Ready(Ok(res?)) } }
  }
  fn poll_flush(...) -> Ready(Ok(()))   // uring writes are not buffered by us
  fn poll_shutdown(...) // submit a shutdown / close; or Ready(Ok(())) and let Drop close
}
```

- The exact `Op` constructors (`Op::read_at`, the write op) are `pub(crate)` — that's why this lives in the fork (reviewer Q6). Match their real signatures (read the fork source).
- `PollIo` must be `Unpin` (all fields are) so `from_raw_socket<S: AsyncRead+AsyncWrite+Unpin>` accepts it.
- **CONTEXT discipline (reviewer Q4):** only construct the op when `rd`/`wr` is `None` (submit once); never re-submit on re-poll.

**Verify on box:** a fork unit/example test — `tokio_uring::start(async { let (a,b)=loopback; write "ping" via PollIo; read it back })` → asserts round-trip. Run on the box (real io_uring).

**BLOCKED fallback:** if `Op` field-storage fights the borrow checker, box it: `Option<Pin<Box<dyn Future<Output=BufResult<usize,Vec<u8>>>>>>` (Op is Unpin so Box+Pin is trivial) — slightly more alloc, same semantics.

## T4 — brust: 414 root cause — Linux read_request appends

```rust
pub async fn read_request(&mut self, buf: &mut Vec<u8>) -> std::io::Result<usize> {
    let owned = vec![0u8; 4096];
    let (res, owned) = self.0.read(owned).await;
    let n = res?;
    buf.extend_from_slice(&owned[..n]);   // APPEND (was: mem::take + reassign)
    Ok(n)
}
```
