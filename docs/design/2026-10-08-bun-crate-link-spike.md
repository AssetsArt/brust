# Spike report: linking Bun's Rust crates from Cargo.toml (2026-10-08)

Verdict: GO. Bun's parser, AST, printer and React Compiler can be consumed as git
dependencies and driven from an external crate; HIR / reactive scopes are reachable
with a 44-line patch to `bun_react_compiler`.

Pinned rev: oven-sh/bun 620b50f6abea3413a30235c5885bfe8cbffd592d (main, after 1.4.2).
Note: `src/sema/standalone/native.rs` does NOT exist at tag bun-v1.4.2 — pin >= main HEAD.

## Measurements (Apple Silicon, nightly-2026-09-15, dev opt-level=1)
- cargo fetch (full monorepo clone, ~/.cargo/git/db 440MB): 1m15s
- cold build of all Bun crates in the graph: 1m13s wall / 306s CPU
- incremental rebuild after patching react_compiler: 43s; spike-only rebuild: <1s
- parse TSX + React Compiler + print: 2–5ms; HIR analysis alone: 2.2ms

## What had to be provided
1. Toolchain: nightly-2026-09-15 (Bun's rust-toolchain.toml; `#![feature(allocator_api)]`).
2. Codegen inputs via BUN_CODEGEN_DIR (.cargo/config.toml [env]):
   - build_options.rs hand-written (16 consts; SHA must be 40 chars or const-eval panics)
   - json_byte_class.rs / xml_byte_class.rs generated by Bun's own scripts
     (`scripts/build/{json,xml}ByteClass.ts`, invoked with `bun`).
3. Native stubs: copy of `src/sema/standalone/native.rs` (847 lines) + 8 more symbols the full
   visit path needs: Bun__JSC__operationMathPow, JSC__jsToNumber, Bun__WTFStringImpl__destroy,
   simdutf__convert_utf8_to_utf16le_with_errors, URL__getFileURLString, __bun_macro_context_call,
   and the TranspilerCacheImpl Jsc dispatch (via `bun_ast::link_impl_TranspilerCacheImpl!`).
4. Extra deps for native.rs: bstr, bun_threading.

## HIR access
- Public already: HirFunction, ReactiveFunction, ReactiveScope, Environment, Host trait,
  collect_import_bindings, ReactCompilerOptions.
- Crate-private: lowering::lower, pipeline::compile_fn/run_hir_passes, FunctionNode, ProgramContext.
- Patch (44 lines): make those pub + add `pipeline::analyze_fn(...) -> (ReactiveFunction, Environment)`
  that stops before codegen. Upstreamable.
- Host over a parsed Ast: ~40 lines; only read-side methods are exercised during analysis
  (no new_generated/new_local/add_import_record calls happened).

## Output for fixtures/ThemeToggle.tsx (useState + useEffect + onClick)
scope 3 deps=[mode*] decls=[t1,t2]        -> effect + deps array depend on `mode`
scope 5 deps=[]      decls=[t3]           -> onClick handler is constant
scope 6 deps=[themeLabel*, label*] decls=[t4] -> JSX depends on prop + derived value
(`label` has no scope: primitives are not memoised; its dependency on `mode` is in the
instruction stream of the ReactiveFunction body.)

## Risks / costs
- No semver: pin `rev`, re-sync by hand; AST and Host trait may change any release.
- Nightly toolchain pinned to Bun's.
- JSX runtime auto-import (`jsxDEV_xxx`) is added by the bundler stage, not the parser —
  our pipeline must add runtime imports itself or bundle through `bun build`.
- Macro/transpiler-cache/URL stubs are panics or no-ops; keep `features.no_macros = true`.

Spike artifacts (throwaway): scratchpad/bun-link-spike (crate, Cargo.git.toml = git-dep form),
scratchpad/bun-patched (patched checkout), scratchpad/bun-src (sparse clone for grep).
